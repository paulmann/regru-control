# Участие в разработке

Спасибо за интерес к проекту.

## Перед PR

1. `php tools/lint.php` — синтаксис и `strict_types`.
2. `php backend/tests/run.php` — все тесты зелёные.
3. `php tools/secret-scan.php --repo=.` — нет секретов и персональных данных.
4. Для UI — ручной проход по затронутым страницам в тёмной и светлой теме, Desktop и 390 px.

## Правила

- Один PR — одна логическая правка; опишите мотивацию и сценарий проверки.
- Новые функции сопровождайте тестом и обновлением `docs/API.md`/`docs/USER-GUIDE.md`.
- Не добавляйте Composer/Node-зависимости без обсуждения: проект сознательно ставится без сборки.
- Не коммитьте `.env`, `var/`, реальные домены, IP и пароли. Для локальных проверок используйте `example.com` и `203.0.113.0/24` (TEST-NET-3).
- Стиль: `docs/DEVELOPMENT.md`.

## Сообщения об ошибках

Приложите: версию (`regru version`), PHP, шаги воспроизведения, `request_id` из ответа и фрагмент `var/log/app.log` **без секретов**.
