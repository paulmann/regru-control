# Установка

## Требования

- PHP **8.5** (FPM + CLI), расширения: `curl`, `json`, `mbstring`, `openssl`, `pdo_sqlite`, `sodium`.
- nginx/Apache с `try_files`/rewrite.
- HTTPS (панель хранит пароли).
- IP сервера в белом списке REG.RU API.
- Composer, Node и база данных **не нужны**.

## Локально

```bash
cp .env.example .env
php backend/bin/regru key:generate
php backend/bin/regru migrate
php backend/bin/regru user:create --login=admin --password='Local-Dev-Passw0rd!'
php backend/bin/regru serve --port=8099
```

Откройте `http://127.0.0.1:8099`.

## На сервере

1. Соберите дерево публикации: `php tools/build.php --target=../deploy`.
2. Скопируйте его в каталог сайта (веб-корень = каталог с `index.php`).
3. Создайте `.env` (сгенерирует `key:generate`) и примените миграции.
4. Закройте панель списком сетей в nginx, служебные каталоги — `deny all`.
5. Настройте аккаунт REG.RU и выполните синхронизацию.

Пример nginx-блока и настройки деплоя — в репозитории: `docs/DEPLOY.md`, `docs/deploy/nginx-regru-control.conf`.

## Переменные окружения

| Переменная | Смысл | По умолчанию |
|---|---|---|
| `APP_ENV` | `production` / `development` / `test` | `production` |
| `APP_DEBUG` | подробные ошибки | `0` |
| `APP_URL` | публичный адрес | — |
| `APP_KEY` | base64:32 байта | генерируется |
| `DB_PATH` | SQLite-файл | `var/regru.sqlite` |
| `SESSION_SECURE` | cookie только по HTTPS | `1` |
| `REGRU_TIMEOUT` / `REGRU_RETRIES` | сетевые параметры | `20` / `3` |
| `REGRU_RATE_LIMIT_PER_HOUR` | локальный предохранитель | `1100` |

## Первичные доступы

```bash
php backend/bin/regru account:set --login=ВАШ_ЛОГИН --password-stdin
php backend/bin/regru token:create --name=agent --scopes=read,secrets:read --ttl-days=365
```

Пароль API REG.RU отличается от пароля личного кабинета: он создаётся в разделе «Настройки API».

## Cron

```cron
*/30 * * * * cd <APP> && php backend/bin/regru sync --scope=all >/dev/null 2>&1
15 3 * * *   cd <APP> && php backend/bin/regru backup >/dev/null 2>&1
```
