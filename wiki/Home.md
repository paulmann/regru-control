## Что делает панель

| Область | Возможности |
|---|---|
| Инвентарь | домены, хостинги, VPS, выделенные серверы, лицензии, парковки; даты оплаты, автопродление, NS, статусы |
| Домены | продление, автопродление, смена DNS-серверов, снятие с делегирования, сертификат владения, DNSSEC |
| DNS | A, AAAA, CNAME, MX, TXT, NS, SRV, CAA, SOA/TTL; кэш и обновление из реестра |
| Хостинги | IP-адреса, панели, логины; пароли — если REG.RU их отдаёт, иначе в шифрованное хранилище |
| Доступы | libsodium-хранилище паролей с аудитом каждого раскрытия |
| Биллинг | баланс, неоплаченные счета, история |
| API / MCP | scoped Bearer-токены, OpenAPI, 13 MCP-инструментов, raw-вызов любой из 116 команд |
| Эксплуатация | cron-синхронизация, бэкапы SQLite, журнал, `doctor` |

## Коротко о проекте

- PHP 8.5, SQLite, ноль Composer/Node-зависимостей.
- 116 документированных команд REG.RU API v2.
- Шесть языков: `en` (по умолчанию), `ru`, `zh`, `hi`, `de`, `es`.
- 38 автотестов без сети; MCP-сервер с 13 инструментами.

Проект не связан с REG.RU. «REG.RU» — товарный знак соответствующего правообладателя.
