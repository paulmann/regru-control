# REG.RU Control

Панель управления доменами, DNS-зонами и хостингами REG.RU: современный интерфейс для человека и JSON API для интеграций и AI-агентов.

Проект вырос из `daloman/regru-api-go` (три функции DNS-зоны), но переписан с нуля на PHP 8.5 и покрывает весь документированный REG.RU API v2 — 116 команд.

## Что умеет

- **Инвентарь**: домены, хостинги, VPS, выделенные серверы, лицензии, парковки; даты оплаты, автопродление, статусы.
- **Домены**: продление, автопродление, DNS-серверы, снятие с делегирования, сертификат владения.
- **DNS**: A, AAAA, CNAME, MX, TXT, NS, SRV, CAA, SOA/TTL, DNSSEC; безопасное изменение записей.
- **Хостинги**: IP-адреса, панели, логины; пароли — если REG.RU их отдаёт, иначе в шифрованное хранилище вручную.
- **Доступы**: libsodium-хранилище паролей с аудитом каждого раскрытия.
- **Биллинг**: баланс, неоплаченные счета, история.
- **API**: Bearer-токены со scopes, инвентарь для агента, raw-вызов любой команды REG.RU.
- **MCP-сервер**: 13 инструментов для Claude/DSH/Cursor, read-only по умолчанию.
- **Интерфейс**: английский (по умолчанию), русский, китайский, хинди, немецкий, испанский; автодетект и переключатель.
- **Эксплуатация**: cron-синхронизация, резервные копии, журнал действий, диагностика.

## Быстрый старт

```bash
cp .env.example .env
php backend/bin/regru key:generate
php backend/bin/regru migrate
php backend/bin/regru user:create --login=admin
php backend/bin/regru account:set --login=ВАШ_ЛОГИН --password-stdin <<< 'пароль API'
php backend/bin/regru sync --scope=all
php backend/bin/regru serve --port=8099
```
