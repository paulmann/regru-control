# 11 · FAQ

### Это SaaS или самостоятельная установка?

Самостоятельная: панель ставится на ваш сервер и работает с вашим аккаунтом REG.RU. Внешних сервисов, кроме `api.reg.ru`, нет.

### Где хранятся пароли?

В SQLite, зашифрованные libsodium. Ключ — `APP_KEY` в `.env`. Без ключа пароли не восстановить; бэкапьте `.env` отдельно от базы.

### Почему для части хостингов «API не вернул» пароль?

`service/get_details` возвращает `login/passwd/server_ip` не для всех типов услуг. Это ограничение регистратора, а не панели. Пароль можно сохранить вручную в «Доступах» — он будет зашифрован и доступен агенту по API с правом `secrets:read`.

### Почему DNS-страница пустая, хотя домены есть?

Через API управляются только зоны на `ns1.reg.ru`/`ns2.reg.ru`. Домены на `ns5/ns6.hosting.reg.ru` и `ns1/ns2.shop.reg.ru` ведутся в ISPmanager — панель показывает их отдельным списком.

### Можно ли управлять DNS домена, делегированного на Cloudflare?

Нет: зона не в REG.RU. Смените NS на `ns1.reg.ru`/`ns2.reg.ru`, если хотите управлять записями через REG.RU API.

### Как подключить AI-агента?

Создайте токен: `regru token:create --name=agent --scopes=read,secrets:read --ttl-days=365`. Агент использует `GET /api/v1/inventory` для инвентаря и `POST /api/v1/credentials/{id}/reveal` для пароля. Каждое раскрытие попадает в журнал. Для MCP — [страница MCP](06-MCP).

### Агент может выполнить любую команду REG.RU?

Да, если у токена есть `regru:raw`: `POST /api/v1/regru/call`. Выдавайте это право осознанно — команды могут списывать деньги.

### Что с лимитами REG.RU?

Официально 1200 запросов/час. Панель останавливается на 1100 и пишет об этом. Полная синхронизация — около 15 запросов.

### Как обновляться?

`pwsh -NoProfile -File tools/deploy.ps1` (Windows) или сборка + rsync; миграции применяются автоматически, предыдущий релиз архивируется на сервере.

### Как восстановить пароль администратора?

Только с доступом к серверу: `php backend/bin/regru user:passwd --login=admin --password-stdin`.

### Какие языки поддерживаются?

Английский (по умолчанию), русский, китайский, хинди, немецкий и испанский. Язык определяется по `Accept-Language`/cookie/браузеру, переключается в шапке и на экране входа; API отвечает на языке `Accept-Language`.

### Поддерживается ли несколько пользователей?

Да, таблица `users`, но роли две: `admin` и `viewer` (отдельного UI управления пользователями нет; создание — CLI).

### Есть ли тёмная тема?

Да, тёмная по умолчанию, светлая переключается в шапке и запоминается.

### Почему нет публичного демо?

Панель хранит реальные доступы; демо потребовало бы отдельного аккаунта REG.RU и изоляции. Локальный запуск проще и безопаснее.
