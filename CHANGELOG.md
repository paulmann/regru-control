# Журнал изменений

## 1.0.0 — 2026-10-22

Первый публичный релиз: полная переработка исходного `daloman/regru-api-go` (Go, три функции DNS) в самостоятельную панель на PHP 8.5.

### Добавлено

- Инвентарь услуг REG.RU: домены, хостинги, VPS, выделенные серверы, лицензии, парковки; автопродление, даты, статусы, ID услуг.
- Синхронизация вручную и по cron: услуги → NS/автопродление → данные хостингов → DNS-зоны; история запусков и ошибки по этапам.
- Управление доменами: продление, автопродление, DNS-серверы, снятие с делегирования, сертификат владения (партнёрам).
- Редактор DNS: A, AAAA, CNAME, MX, TXT, NS, SRV, CAA; SOA/TTL; атомарное изменение записи; DNSSEC; кэш с обновлением из реестра.
- Хостинги: IP, ссылки на панели, логины; честная пометка «API не вернул» для недоступных данных.
- Шифрованное хранилище доступов (libsodium) с генератором паролей и аудитом раскрытия.
- Биллинг: баланс, неоплаченные счета, история за период.
- JSON API v1 с Bearer-токенами и scopes (`read`, `write`, `dns:write`, `secrets:read`, `admin`, `regru:raw`).
- Каталог 116 документированных команд REG.RU API v2 и raw-консоль для любых из них.
- SPA в тёмной/светлой теме, адаптив до 390 px, CSP без inline-кода, без CDN.
- i18n: английский (по умолчанию), русский, китайский, хинди, немецкий, испанский; автодетект по `Accept-Language`/cookie/браузеру, ручной переключатель, локализованные ошибки API, валидация и названия услуг/статусов.
- MCP-сервер `mcp/server.php` (stdio, JSON-RPC 2.0): 13 инструментов для AI-агентов, read-only по умолчанию, write-операции — только через `REGRU_MCP_ALLOW_WRITE=1`.
- `AGENTS.md` — скачивание, установка, настройка и управление; `docs/MCP.md` — подключение MCP-клиентов.
- CLI: `key:generate`, `migrate`, `user:*`, `account:*`, `sync`, `dns:*`, `api:call`, `token:*`, `doctor`, `backup`, `routes`, `serve`, `test`.
- Инструменты: `tools/lint.php`, `tools/secret-scan.php`, `tools/build.php`, `tools/deploy.ps1`.
- 38 автотестов без внешних зависимостей и без сети.

### Исправлено относительно исходного проекта

- Ошибки API больше не проглатываются: различаются транспортные и бизнес-ошибки, есть коды и человекочитаемые сообщения.
- Параметры ответа (`prio` строкой/числом) нормализуются; список записей не теряется при изменении типа поля.
- Добавлены таймауты, повторы только для сетевых сбоев и защита от двойного списания при продлении.
- Учёт лимита 1200 запросов/час (локальный предохранитель 1100).
- Секреты не попадают в логи и списки API.

### Известные ограничения

- REG.RU не отдаёт пароли панелей для части типов услуг — такие пароли можно сохранить вручную.
- Управление DNS через API доступно только для зон на `ns1.reg.ru`/`ns2.reg.ru`.
- Публичного демо нет: панель рассчитана на приватное развёртывание.
